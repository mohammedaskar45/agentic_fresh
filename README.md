# Agentic Compliance Operating System 🚀🏛️

An enterprise-grade, AI-orchestrated platform for automated corporate incorporation and statutory compliance management in India.

## 🌟 Key Features

- **11-Step Agentic Workflow**: End-to-end incorporation lifecycle management from DSC to Commencement of Business.
- **AI-Powered Legal Drafting**: Automated generation of MOA, AOA, and statutory declarations with real-time legal preview.
- **Strict Statutory Validation**: Multi-director support (DIN) with MCA-compliant field validations (Father's name, PAN, Address history).
- **Dynamic Digital Vault**: Secure storage for all generated legal certificates and forms.
- **Real-time Progress Tracking**: Dashboard metrics for Time Elapsed, Pending Tasks, and Completion Percentage.

## 🛠️ Tech Stack

**Frontend:**
- React 18 + Vite
- TanStack Router & Store
- Tailwind CSS + Shadcn UI
- Lucide Icons & Framer Motion (Animations)

**Backend:**
- NestJS (Node.js Framework)
- TypeORM + PostgreSQL
- JWT Authentication & RBAC
- Agentic Service Architecture

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- PostgreSQL Database
- npm / pnpm

### Backend Setup (`/agentic-admin_api`)
1. `npm install`
2. Create `.env` file with database credentials.
3. `npm run build`
4. `npm run start:dev`

### Frontend Setup (`/agentic-admin`)
1. `npm install`
2. `npm run dev`

## 📊 Incorporation Roadmap
1. **DSC**: Digital Signature acquisition.
2. **DIN**: Director Identification allotment.
3. **RUN**: Name Reservation with NIC classification.
4. **Drafting**: AI-orchestrated MOA & AOA.
5. **ROC Filing**: SPICe+ statutory submission.
6. **Tax ID**: PAN & TAN allotment.
7. **COI**: Certificate of Incorporation receipt.
8. **Bank**: Corporate account opening.
9. **GST**: Tax registration.
10. **Labor**: PF & ESI compliance.
11. **Commencement**: INC-20A filing.
